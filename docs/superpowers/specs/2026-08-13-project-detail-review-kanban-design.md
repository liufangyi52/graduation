# 项目详情、AI 审核详情与任务看板设计

## 目标

完成 P0 协作闭环：项目成员可在项目详情中查看受权限约束的数据；项目经理可在可追溯的审核详情中编辑候选结果、填写驳回原因并进行审核；任务列表可在表格和看板间切换，并按业务条件筛选。

## 范围与边界

- 新增 `/projects/:id` 项目详情页，提供概览、任务、会议、风险、成员五个 Tab；新增 `/projects/:id/meetings` 作为会议 Tab 的可链接入口。
- 新增 `/meetings/:id/review` 审核详情页。审核记录不修改 AI 原始运行结果；候选任务编辑保存在审核草稿中，审核通过时以草稿为准生成正式任务。
- `/tasks` 提供表格/看板切换，支持项目、负责人、状态、优先级、风险和截止日期范围筛选。
- 延续现有角色边界：项目经理只能管理自己拥有的项目；成员只能访问参与项目且只更新本人任务；管理员和审计员只读业务数据。
- 本批不实现 RAG、智能体编排、实验中心、甘特图、导出、分页或排序。

## 架构

保留 `App.vue` 作为已登录壳层、导航和全局通知，将页面主体拆为三个 Vue 组件：`ProjectDetailPage.vue`、`MeetingReviewPage.vue` 和 `TaskBoardPage.vue`。路由参数决定当前项目或会议；组件通过扩展后的 `workspaceService` 与 `meetingService` 调用 REST API，并在写操作成功后刷新权威服务端数据。

服务端新增项目详情聚合读取接口，以及审核草稿读取/保存接口。`ai_analyses.result_json` 保持原始 AI 结果不变；审核草稿存放在独立字段或关联表中，记录候选任务、决议和审核时使用的证据定位信息。审批事务读取草稿（若存在）生成正式任务，并继续保留审核、重分析、通知、审计与软删除项目约束。

## 项目详情

`GET /projects/:id/detail` 返回项目基本信息、当前用户权限标志、成员、项目任务、会议摘要、风险摘要和完成率。页面顶部显示名称、状态、负责人、成员数、完成率和截止日期。

- 概览 Tab 显示项目描述、任务状态统计、待审核数和风险摘要。
- 任务 Tab 仅显示本项目任务，点击进入现有任务详情；项目经理可进入编辑/新建任务。
- 会议 Tab 显示会议标题、创建时间、版本数与最新审核状态，并能进入 `/meetings/:id/review`。
- 风险 Tab 显示项目风险和处理状态；仅项目经理能标记处理。
- 成员 Tab 显示成员和项目角色；仅项目经理出现成员增删入口。

项目不存在、已软删除或当前用户无权限时，页面显示明确的无权/不存在状态，不泄露项目数据。

## AI 审核详情与驳回

`GET /meetings/:id/review` 返回会议当前脱敏版本、关联分析记录、审核草稿和只读证据片段。页面采用左右布局：左侧显示脱敏纪要和根据证据偏移定位的高亮片段；右侧显示摘要、决议和可编辑候选任务。

- 项目经理可编辑候选任务的标题、描述、建议负责人、截止日期、优先级和风险等级；保存草稿不改变原始 AI 结果。
- 驳回必须填写 1–500 字原因；单条和批量驳回均使用同一校验。批量操作先显示选中数量并二次确认。
- 审核通过时，服务端事务使用草稿候选任务生成正式任务；驳回保留草稿、原因和原始记录。仅被驳回的记录可重新分析，新记录仍保留 `reanalysis_of_id`。
- 成员可查看已通过的结果，不能编辑、审核或查看敏感原文；管理员和审计员保持只读。

## 任务看板与筛选

`TaskBoardPage.vue` 复用现有任务读取结果，但增加纯前端组合筛选和视图状态：项目、负责人、状态、优先级、是否关联未处理风险、截止日期起止。筛选条件保留在 URL query 中，便于从项目详情、仪表盘和通知中心跳转后复现。

表格和看板使用同一份过滤结果。看板按 `todo`、`in-progress`、`completed`、`closed` 四列分组；卡片显示项目、负责人、优先级、截止日期和进度。状态推进仍调用现有权限受控 API，不通过拖拽直接绕过状态机。

## 错误处理与审计

所有写入操作在页面中禁用重复提交并展示服务端错误。删除、归档、恢复、批量通过、批量驳回和关闭任务均需二次确认。审计仅记录对象 ID、变更字段和计数；不写入纪要文本、候选任务描述、备注或驳回原因。

## 验收与测试

- 新增路由和组件静态/行为测试，验证项目详情 Tab、审核详情、驳回原因校验、草稿保存、批量确认、看板列和筛选 URL 参数。
- 增加服务测试：项目详情数据隔离；驳回无原因失败；审批使用草稿生成任务；非经理不能编辑审核草稿。
- 扩展 MySQL 冒烟脚本：创建项目和会议、保存审核草稿、带原因驳回、重分析、审批草稿并验证正式任务字段。
- 完成后运行 `npm test`、`npm run build`、`npm run smoke:project-core-closure` 和健康检查。

## 自检

范围限定为三个 P0 页面闭环；每个新增写操作均有权限、服务端校验、刷新和审计边界。草稿与原始 AI 结果分离，避免审核编辑破坏运行历史。未包含实验、RAG、导出等后续功能。
