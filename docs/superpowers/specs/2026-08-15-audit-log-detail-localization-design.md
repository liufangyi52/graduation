# 审计日志对象与详情中文化设计

## 目标

将审计日志页面中面向用户展示的对象类型和详情内容转换为中文，消除 `user`、`project`、`status`、`manager` 等英文标签，同时保留对象 ID 以支持审计追溯。

## 展示规则

- 对象类型映射为中文：`user`、`project`、`task`、`risk` 等分别显示为“账号”“项目”“任务”“风险”。未识别类型保留原值。
- 对象栏保持“中文类型 / 原始 ID”的结构，例如“账号 / 9f9d...”。
- 详情字段映射为中文可读文本。已知字段包括角色、状态、项目 ID、索引分块数和进度；角色与状态的枚举值也转换为中文。
- 空对象详情显示为“无变更详情”。无法解析的旧记录或未知字段保留原始内容，保证日志不因展示层转换而丢失信息。

## 实现边界

- 新增前端展示辅助函数及单元测试，并在完整审计日志页和仪表盘最近审计记录中复用对象标签。
- 后端仍保存原始 `entity_type`、`entity_id` 和 JSON `details`，不修改数据库迁移、API 契约或既有审计记录。

## 验证

- 覆盖对象类型、角色、状态和未知值的映射测试。
- 覆盖 App 页面使用中文展示辅助函数的回归测试。
- 运行对应 Vitest 用例与生产构建。
