# 全局时间格式统一设计

## 目标

项目内所有用户可见的只读时间统一显示为北京时间，精确到分钟，格式为 `YYYY-MM-DD HH:mm`。页面和导出内容不再暴露包含 `T`、`Z`、秒或毫秒的原始 ISO 字符串。

本设计扩展并取代仅覆盖通知时间的 `2026-08-15-notification-time-format-design.md`。

## 根因

接口与前端状态保留原始日期时间值，但多个 Vue 模板和导出行构造器直接输出这些值。浏览器因此显示数据库驱动序列化产生的 ISO 字符串。项目已经提供 `formatBeijingMinute(value: string): string`，但目前只有少量页面使用。

## 方案

采用展示边界格式化：接口、数据库和前端状态继续保留原始值，只在 Vue 模板和导出行中调用 `formatBeijingMinute()`。不在服务映射层或后端格式化，以免破坏日期比较、表单回填、日历计算和 API 的通用性。

### 页面范围

- `App.vue`：AI 审核时间、即将到期任务、审计日志、项目截止时间、任务发布时间、成员反馈时间、通知时间、会议版本时间、任务详情截止时间、任务备注时间和项目删除时间。
- `TaskBoardPage.vue`：任务列表截止时间。
- `ProjectDetailPage.vue`：任务截止时间、会议创建时间和风险创建时间；保留已经使用 `formatBeijingMinute()` 的项目截止时间与同步时间。
- `projectExport.ts`：任务与会议导出中的创建时间和截止时间。

成员提交反馈后不再把 `createdAt` 写成“刚刚”，而是写入当前 ISO 时间，再在界面使用 `formatBeijingMinute()`。

### 明确例外

以下值表达的是日历日期或输入值，而不是只读时间戳，因此保持纯日期格式：

- `type="date"` 日期输入和任务日期筛选。
- 团队日历中的年月日、今天和日期单元格。
- 甘特图日期轴与按日统计标签。
- 导出文件名中的生成日期。

持续时间指标，例如分析耗时的 `ms`，不是日期时间，不调用该格式化函数。

## 缺失与无效值

复用 `formatBeijingMinute()` 的现有降级行为。缺失、占位或无法解析的时间显示为 `-`，不抛出界面错误。
