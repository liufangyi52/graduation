# 甘特图状态与截止日期表达设计

## 目标

重做项目分析页的甘特图，让任务状态固定为三种，并将状态与截止日期风险同时呈现在每一行中。

## 状态模型

甘特任务条只使用三种状态：

- `已完成`：任务状态为 `completed` 或 `closed`，或进度达到 100%。
- `进行中`：任务未完成且已有实际进度，或任务状态为进行中。
- `未完成`：任务未完成且没有实际进度。

状态通过不同方框样式表达：未完成使用浅灰边框与浅底色，进行中使用蓝色实底，已完成使用绿色实底。图例和行内标签使用同一套语义。

## 截止日期风险

时间风险独立于状态展示，使用截止日期与当天日期计算：

- 未完成/进行中且截止日期早于当天：`已逾期`，红色。
- 未完成/进行中且距离截止日期为 0 至 3 天：`临近截止 · 剩 X 天`，橙色。
- 其他未完成/进行中任务：显示正常截止日期，不额外添加风险标签。
- 已完成任务不显示逾期或临期风险。

甘特图保留今天竖线、日期轴和每项任务的起止日期，确保风险提示可以和时间位置对应。无有效日期的任务继续放入未排期提示，不参与时间风险计算。

## 实现边界

使用现有 `buildProjectAnalytics` 返回的日期比例和任务字段，不新增图表依赖，不修改任务生命周期或导出逻辑。状态归一化和截止日期风险计算放在纯函数中，Vue 组件只负责渲染。

## 验证

补充分析工具函数测试，覆盖三种状态、逾期、3 天内临期、已完成不标风险和无效日期。补充 UI 源码测试，确认图例、状态标签和风险标签存在；最后运行相关 Vitest 测试及生产构建。
