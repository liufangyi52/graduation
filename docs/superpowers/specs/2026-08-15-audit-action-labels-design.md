# 审计操作中文名称设计

## 目标

将所有审计日志视图中的机器事件码显示为清晰、统一的中文操作名称，让管理员和审计人员能够直接理解系统操作。

## 范围

- 新增一个纯前端事件码显示工具，接收审计事件码并返回中文名称。
- 管理员首页、审计员首页和“审计日志”全量页面统一调用该工具。
- 覆盖当前服务端产生的审计事件码，包括项目、任务、会议、风险、账号、通知、系统设置、导出和 RAG 索引操作。
- 未映射的事件码保持原样显示，确保未来新增事件仍可追溯。

## 非目标

- 不修改数据库中的 `audit_logs.action` 数据。
- 不修改审计日志接口、权限、筛选或分页逻辑。
- 不改变表格结构、对象标识或详情字段。

## 实现与验证

映射定义为无副作用的 TypeScript 纯函数，并使用 Vitest 验证代表性事件和未知事件的兜底输出。`App.vue` 的三个审计操作单元格只替换显示表达式，继续使用原始日志数据。完成前运行定向测试、完整测试和生产构建，并在现有本地开发服务器中检查三个审计视图。
