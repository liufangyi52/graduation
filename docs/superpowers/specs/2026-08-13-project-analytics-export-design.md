# 项目可视化与导出设计

## 目标

补齐项目系统的可视化分析与结果导出能力。用户在有权限的数据范围内查看项目进度、风险与计划，并将会议纪要、任务清单和项目统计报告即时导出为 Excel 或 PDF。

## 范围与权限

项目经理可查看并导出所负责项目的会议纪要、任务清单和项目统计。项目成员只能查看并导出本人任务清单。系统管理员可操作全部项目。审计员继续只读业务数据，只可导出审计日志，本次不提供业务导出入口。

所有导出请求先由后端根据当前登录用户、项目成员关系和系统角色进行授权。授权成功后写入审计日志，记录操作者、导出类型、项目范围、格式和请求时间。前端只拿到获授权的数据并在本地生成文件；系统不保存导出文件。

## 分析数据与口径

项目详情新增“分析”标签页。项目经理和管理员使用项目全部数据，成员使用本人任务数据；会议与风险在成员视图不计入统计，以免暴露项目级内容。

指标包括任务总数、已完成任务数、完成率、逾期任务数、开放风险数和会议数。完成率为已完成任务数除以任务总数，任务总数为零时显示“暂无任务”，不展示虚假的 0% 图表。逾期任务是截止日早于今天且状态不是“已完成”或“已关闭”的任务。开放风险为状态不是“已处理”的风险。

任务完成趋势按任务实际完成日期分组；当前数据没有独立完成时间时，使用任务状态变更的审计记录作为完成日，缺少记录的历史任务不进入趋势图。甘特图使用任务创建时间作为开始日、截止日作为结束日；没有截止日的任务单独列在“未设置截止日”，不绘制跨期条。

风险分布按低、中、高三级统计，只展示有风险数据的等级。

## 页面交互

项目详情的标签增加“分析”。分析页从同一项目详情接口取得任务、风险和会议，避免与列表页的统计口径分裂。页面依次展示指标卡、任务完成趋势、风险分布和甘特图；空数据展示说明，不绘制零值图形。

项目详情头部提供项目级导出菜单，仅对项目经理和管理员显示，包含“会议纪要”“任务清单”“项目统计”三个对象和 Excel、PDF 两种格式。任务看板提供“导出我的任务”入口，对项目成员、项目经理和管理员显示；成员始终只能得到本人任务，即使页面筛选条件包含其他任务。

导出按钮在请求过程中禁用并显示进行中状态；后端返回无权限、无数据或数据加载失败时，页面显示简短错误，不下载空文件。

## 导出内容

会议纪要 Excel 包含会议标题、创建时间、最新审核状态、摘要、决议和版本数；PDF 使用项目名称、导出日期和会议逐项摘要。任务清单 Excel 包含项目、标题、描述、负责人、优先级、状态、进度、创建时间和截止日；PDF 提供同样字段的表格。项目统计 Excel 包含指标、数值、任务趋势、风险分布和任务明细；PDF 展示项目基本信息、关键指标、趋势、风险和甘特概览。

文件名使用项目名称、导出对象和导出日期。文本字段使用 UTF-8，Excel 使用标准 `.xlsx`，PDF 使用 A4 横向页面，以便任务表格阅读。

## 技术设计

后端新增受权限保护的导出数据接口，而非直接导出二进制文件。接口根据导出对象和项目标识返回结构化数据与显示元数据，并新增审计记录。统计计算抽取为共享纯函数，供项目详情与导出接口调用，保证页面和下载文件一致。

前端使用轻量浏览器库生成 `.xlsx` 与 PDF，不增加服务端文件保存、队列或第三方存储。图表优先采用可测试的 CSS/SVG 原生视图，不引入重量级图表框架；甘特图使用固定日期轴和任务条，趋势及风险使用语义化柱状图。

## 错误处理与测试

后端测试覆盖项目经理、成员、管理员和审计员的导出授权边界，验证成员不能导出项目级数据且每次成功导出均写审计记录。统计测试覆盖空任务、逾期、关闭任务、缺少截止日、风险分级和成员范围收缩。前端测试验证分析标签、空状态、导出按钮可见性和任务看板成员入口。构建、全部单元测试与真实 MySQL 闭环冒烟测试作为完成前验证。
