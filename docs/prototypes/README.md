# 高保真原型图

本目录包含“基于会议纪要智能体的任务抽取与项目进度跟踪系统”的静态高保真原型图。全部页面采用 1440 x 900 像素桌面端画布，按核心业务链路排序。

| 文件 | 页面 | 主要角色 |
|---|---|---|
| `01-dashboard.png` | 项目经理工作台 | 项目经理 |
| `02-project-detail.png` | 项目详情与甘特图 | 项目经理 |
| `03-meeting-import.png` | 会议纪要导入 | 项目经理 |
| `04-ai-review.png` | AI 解析结果复核 | 项目经理 |
| `05-task-board.png` | 任务看板 | 项目经理 |
| `06-risk-center.png` | 风险中心 | 项目经理 |
| `07-my-tasks.png` | 我的任务 | 项目成员 |
| `08-task-feedback.png` | 任务反馈 | 项目成员 |
| `09-settings.png` | 系统设置 | 系统管理员 |
| `10-audit-log.png` | 审计日志 | 审计人员 |
| `meeting-task-system-high-fidelity-prototype.pdf` | 含封面的合并演示稿 | 全部角色 |

重新生成所有输出：

```powershell
npm run prototype:export
```
