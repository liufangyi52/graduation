# 高保真原型图

本目录包含“基于会议纪要智能体的任务抽取与项目进度跟踪系统”的角色化静态界面截图、系统架构图和演示稿。图片按登录入口、项目经理、项目成员、系统管理员和审计人员分组。

## 登录入口与架构

| 文件 | 内容 |
| --- | --- |
| `登录界面.png` | 登录界面 |
| `注册界面.png` | 注册界面 |
| `系统架构图.png` | 业务闭环、系统分层、AI/RAG 和安全保障架构 |

## 项目经理

`项目经理1.png` 至 `项目经理10.png` 展示项目经理工作台、项目管理、任务管理、风险中心、会议纪要、AI 审核、实验中心和项目分析等页面。

## 项目成员

`项目成员1.png` 至 `项目成员11.png` 展示项目成员工作台、我的任务、任务详情、工作反馈、通知和团队日历等页面。当前目录未包含编号 7 的截图。

## 系统管理员

`系统管理员1.png` 至 `系统管理员5.png` 展示账号管理、系统设置、通知和权限相关页面。

## 审计人员

`审计人员1.png` 至 `审计人员3.png` 展示审计人员可访问的业务只读视图和审计日志页面。
